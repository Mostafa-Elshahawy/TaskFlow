# TaskFlow 

TaskFlow is a Jira-inspired task management app built with .NET 9.
It allows organizations to create projects, assign managers and members, and manage tasks efficiently using CQRS and the Repository Pattern.

## Features

- Organization & role management (Managers, Members)

- Project creation & assignment

- Task creation, assignment, and tracking

- Authentication & authorization with ASP.NET Identity

- Clean architecture with CQRS (MediatR) and Repository Pattern

## Tech Stack

Backend: .NET 9, ASP.NET Core Web API

Data: EF Core, SQL Server

Auth: Identity

Patterns: CQRS, Repository, Solid principles, OOP
